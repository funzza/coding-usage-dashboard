# Changelog

## [0.2.0] - 2026-08-26

First public release.

### Added

- WSL default-distro collector: ccusage plus UNC reads for ZCode / DSH / Kimi credentials
- Origin filter (All / Win / WSL) on Overview
- Quota round-trip history used by the float ball ring
- Product screenshots in `docs/images/`

### Changed

- Overview layout: quota strip on every range, Today vs 7D/30D/All compositions
- Subscriptions page owns quota account management (moved out of Settings)

## [0.1.0] - 2026-08

First private build.

- Multi-agent usage via ccusage + ZCode / DSH / Qoder adapters
- Quota monitoring for Kimi / ChatGPT / OpenCode Go / Grok
- Today / Weekly / Monthly / All charts, Sessions, float ball, tray, auto-launch
- Six skins: Focus / Classic / Paper / Mono / Neon / Blueprint
